1. plugins: kích hoạt và bổ sung các tính năng hoặc công cụ cần thiết- id 'java': Kích hoạt các tính năng liên quan đến việc phát triển ứng dụng Java.- Không cần buildscript nữa vì Gradle hiện đại sử dụng plugins block để quản lý plugin một cách trực tiếp và rõ ràng.2. allprojects: áp dụng cho all project3. subprojects: chỉ app dụng cho các module----------------------------------------------------- Muốn xóa hẳn dependent    + xóa trong caches: rm -rf ~/.gradle/caches- group: Namespace: đại diện cho một tổ chức hoặc nhóm phát triển phần mềm----------------------------------------------------- lombok    	•   implementation: Cần thiết nếu ứng dụng của bạn yêu cầu Lombok trong runtime (ít gặp nhưng đôi khi cần).    	•	compileOnly: Đảm bảo Lombok chỉ được sử dụng trong thời gian biên dịch, không bị đưa vào ứng dụng cuối cùng.    	•	annotationProcessor: Kích hoạt tính năng xử lý annotation của Lombok trong giai đoạn biên dịch, giúp Lombok hoạt động đúng cách.- @SpringBootApplication(exclude = {DataSourceAutoConfiguration.class }) tự động config database khi chưa dùng đến-------- application.ymlspring:  autoconfigure:    exclude:      - org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration-> tự động auto config trong yml không cần sửa code----------------------------------------------------OpenAPI Documentation đủ config để lên swagger        implementation 'org.springdoc:springdoc-openapi-starter-webmvc-ui:2.6.0'        implementation 'org.springdoc:springdoc-openapi-ui:1.7.0'----------------------------------------------------Security: viết chung có cả project - phần security sẽ viết trong framework----------------------------------------------------Mức độ ưu tiên của file config1.	file:./config/→ Ưu tiên cao nhất trong số các file properties (nằm ngoài project, trong thư mục config cùng cấp file jar).	2.	file:./→ Nếu không có ./config/ thì lấy từ đây (cùng cấp file jar).	3.	classpath:/config/→ Thư mục src/main/resources/config/ trong project.	4.	classpath:/→ Thư mục gốc src/main/resources/ trong project.
